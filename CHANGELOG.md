# Changelog

All notable changes to this project. Each entry links to its full per-version file in [changelog/](changelog/).

## [0.2.1](changelog/0.2.x/0.2.1.md) — 2026-10-31 · 🛡️ Security

Search a past Parliament's House roster and open former members' profiles, read and search French Hansard, get royal assent and reading times as UTC instants, match text filters across accents, dashes, and quotes, and see each fixed input format in the tool schemas; text and vocabulary filters run in time linear in the value's length.

## [0.2.0](changelog/0.2.x/0.2.0.md) — 2026-10-28

A Canadian Parliament research guide connects bill, member, division, and Hansard evidence, and current House session routes restore division queries and member ballots.

## [0.1.3](changelog/0.1.x/0.1.3.md) — 2026-10-24

Verified member identity variants and bounded search pages with explicit official-source refusals.

## [0.1.2](changelog/0.1.x/0.1.2.md) — 2026-10-21

Bill dossiers gain legislative summaries, notes, web references, and reading milestones; member ballots come from the official feed; vote ballots filter by value and member; bill, vote, and speech replies share one 24,000-byte budget; member-identity, split-bill-code, and rendering bugs fixed.

## [0.1.1](changelog/0.1.x/0.1.1.md) — 2026-10-20

Eight tools for Canadian federal bills, MPs, House votes, and Hansard speeches.
