# 0.3.0 — 2026-11-23

## Added

- **`canparl_get_bill_text`** ([#38](https://github.com/cyanheads/canada-parliament-mcp-server/issues/38)): reads one version of a bill as plain text from its official XML (`introduction`, `headings`, numbered `body` sections, `schedules`), English or French; `publicationId` comes from `canparl_get_bill` `publications` and defaults to the last-listed version. Text over 24,000 bytes returns an outline; page one `segment` with `offset` and `limit`, sections never split. A version published only as a PDF or table-of-contents cover fails `bill_text_unavailable` (common before 42-1); a DocumentViewer page served with 200 that holds neither the export link nor publication content is retried as a transient failure, never reported as "no text".
- **`canparl_search_members` `postalCode`** ([#35](https://github.com/cyanheads/canada-parliament-mcp-server/issues/35)): returns the sitting MPs whose ridings contain a complete Canadian postal code, every one when it spans ridings; combines with the other filters by AND, and `includeFormer` or `parliament` reject it with `unsupported_historical_filter`. A code with no sitting MP returns an empty page with a notice.
- **`canparl_get_bill` `similarBills`, `reinstatement`, `interChamberMessages`** ([#37](https://github.com/cyanheads/canada-parliament-mcp-server/issues/37)): earlier and related versions (newest session first), reinstatement links to the previous or next session's bill, and the House–Senate messages and amendment exchanges; 17 sections in total, `reinstatement` also inline in the outline. The added data moves some unselected dossiers past the 24,000-byte outline threshold: 12 of 371 sampled, such as 41-2 C-201, now return an outline, and every field stays reachable by section.
- **Former-MP disclosure** ([#39](https://github.com/cyanheads/canada-parliament-mcp-server/issues/39)): a digit-only `canparl_search_bills` `sponsor`, `canparl_search_speeches` `politician`, or `canparl_get_member` `slug` that is also a former MP's `personId` adds a notice naming both people; `sponsor_not_found`, `speech_entity_not_found`, and `member_not_found` gain a hint routing those digits to `canparl_get_member` `personId`.

## Changed

- **Pages are bounded by `limit` alone** ([#29](https://github.com/cyanheads/canada-parliament-mcp-server/issues/29)): the 24,000-byte page cut is removed from `canparl_search_bills`, `canparl_search_votes`, `canparl_search_members`, `canparl_get_vote`, `canparl_search_speeches`, and `canparl_get_bill` sections, so `limit: 100` on bill search returns 100 rows, not 14. The 24,000-byte threshold remains only for an unselected `canparl_get_bill` dossier and `canparl_get_bill_text`.
- **`canparl_get_member` official ballots** ([#36](https://github.com/cyanheads/canada-parliament-mcp-server/issues/36)): `recentVotes` takes up to 100 per call (was 10), and `recentVotes.total` is the exact ballot count after `votesBillCode` (was always `null`; **breaking**, a client validating against 0.2.1's `{"type":"null"}` schema rejects the integer). Rows add `yeas`, `nays`, `paired`, and `documentType`, each `null` when absent. OpenParliament ballots stay at 10 with a `null` `total`.
- Caller-input and not-found failures log at `notice` instead of `error`; the wire is unchanged.

## Fixed

- The empty `canparl_search_members` notice said "broaden name or riding" when only province, party, or postal filters were set; it now says "broaden or remove a filter".
- Province inputs and hints on `canparl_search_members` and `canparl_get_vote` called the two-letter abbreviations "postal codes" or a "province code"; they now say two-letter abbreviation.
