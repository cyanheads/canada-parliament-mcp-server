# 0.1.1 — 2026-10-20

## Added

- **Bills:** search official LEGISinfo records across both chambers and retrieve dossiers with whole-record section pagination for large responses. ([#1](https://github.com/cyanheads/canada-parliament-mcp-server/issues/1), [#2](https://github.com/cyanheads/canada-parliament-mcp-server/issues/2))
- **Members:** search the current House roster or historical OpenParliament index, then retrieve profiles, dated memberships, sponsored bills, and recent ballots.
- **Votes:** search recorded House divisions and retrieve official tallies, party totals, and paginated individual ballots.
- **Hansard and references:** search indexed House speeches by speaker, bill, date, or literal English text; discover source-specific sessions and filter vocabulary.
- **Client output and runtime:** preserve source values and provenance on both Markdown and structured response surfaces, with explicit continuations and unavailable data; support STDIO and Streamable HTTP without upstream API keys.
- **Distribution:** scoped npm package, MCP Registry metadata, Claude Desktop bundle, editor plugins, and multi-architecture container image.
