# 0.1.3 — 2026-10-24

## Changed

- **Search pages** fit complete bill, division, and current/historical member rows within the shared 24,000-byte response budget, with continuation and explicit oversized-record disclosure ([#20](https://github.com/cyanheads/canada-parliament-mcp-server/issues/20)).
- **Hosted access** is documented for Claude Code, Cline, Cursor, and Claude Desktop and advertised in the MCP Registry metadata.
- **Development tooling** syncs framework guidance and classifies dependency advisories against the installed root version.

## Fixed

- **Member identity** verifies official IDs against recorded names or published aliases, using bounded surname discovery after an empty exact-name lookup to accommodate accents and middle initials ([#18](https://github.com/cyanheads/canada-parliament-mcp-server/issues/18)).
- **Official-source refusals** return source-named `upstream_blocked` failures with retry-later recovery, without response HTML, retries, or failure caching ([#21](https://github.com/cyanheads/canada-parliament-mcp-server/issues/21)).
