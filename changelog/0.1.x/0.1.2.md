# 0.1.2 — 2026-10-21

## Added

- **`canparl_get_bill`** returns the Library of Parliament legislative summary, dossier notes, web references, sponsor title, and reading milestones; dossiers outline 14 sections. ([#10](https://github.com/cyanheads/canada-parliament-mcp-server/issues/10))
- **`canparl_get_vote`** `ballot` and `personId` filters on the ballot page. ([#8](https://github.com/cyanheads/canada-parliament-mcp-server/issues/8))
- **`canparl_get_member`** reads recent ballots from the official OurCommons member-votes feed; new `votesSession` and `votesBillCode` inputs, additive row fields (`officialBallot`, `source`). ([#9](https://github.com/cyanheads/canada-parliament-mcp-server/issues/9))
- **Member identity:** a current MP's official personId passed as `slug`, `sponsor`, or `politician` (bare digits, or its `/politicians/<digits>/` path or URL) resolves through the verified roster crosswalk; `appliedFilters` adds `sponsorName` and `politicianName`. ([#4](https://github.com/cyanheads/canada-parliament-mcp-server/issues/4))
- **Response budget:** `canparl_get_bill`, `canparl_get_vote`, and `canparl_search_speeches` share one 24,000-byte complete-response budget. ([#7](https://github.com/cyanheads/canada-parliament-mcp-server/issues/7))
- **Page-size clamping:** over-cap counts up to 10,000 clamp to each tool's cap with a notice instead of rejecting the call. ([#12](https://github.com/cyanheads/canada-parliament-mcp-server/issues/12))

## Changed

- **`canparl_get_vote`** default `limit` 100 → 30. ([#7](https://github.com/cyanheads/canada-parliament-mcp-server/issues/7))
- **`latestMajorStage.chamber`** is `House`, `Senate`, or null on both bill tools (`House of Commons` → `House`). ([#5](https://github.com/cyanheads/canada-parliament-mcp-server/issues/5))
- **`royalAssentDate`** is a UTC `…Z` instant on both bill tools. ([#15](https://github.com/cyanheads/canada-parliament-mcp-server/issues/15))
- **`canparl_get_bill`** advertises the stage record once as `$defs.BillStage`. ([#13](https://github.com/cyanheads/canada-parliament-mcp-server/issues/13))
- **Filter errors** name the rejected field and its accepted values without echoing the value; malformed sessions get each tool's session reason, and `error.data` is reshaped. ([#11](https://github.com/cyanheads/canada-parliament-mcp-server/issues/11))
- **`content[]` text** uses minimal escaping, nested blockquotes, and recoverable scalar types; `structuredContent` is unchanged. ([#6](https://github.com/cyanheads/canada-parliament-mcp-server/issues/6))
- **Member recent ballots** come from the official feed when the member has one official personId. ([#9](https://github.com/cyanheads/canada-parliament-mcp-server/issues/9))
- **Slug inputs:** a digit-only `slug`, `sponsor`, or `politician` equal to a current personId now means that member. ([#4](https://github.com/cyanheads/canada-parliament-mcp-server/issues/4))
- **Speech text** keeps a paragraph break where inline text preceded a block element. ([#16](https://github.com/cyanheads/canada-parliament-mcp-server/issues/16))

## Fixed

- **Split-bill codes** (`C-15A`) no longer fail whole sessions; 37-1, 37-2, 38-1, and 40-3 list completely. ([#14](https://github.com/cyanheads/canada-parliament-mcp-server/issues/14))
- **Profile links:** an `http://` politician link no longer fails the whole profile; absolute links are relayed exactly as published. ([#17](https://github.com/cyanheads/canada-parliament-mcp-server/issues/17))

## Dependencies

- `commonmark` 0.31.2 and `@types/commonmark` 0.27.10 added as exact-pinned devDependencies (test-only Markdown decoder).
