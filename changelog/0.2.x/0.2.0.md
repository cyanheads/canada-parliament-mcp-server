# 0.2.0 — 2026-10-28

## Added

- Add the Canadian Parliament research guide as an MCP skill resource.
- **Agent Plugins:** root manifests support plugin discovery alongside the existing Claude Code and Codex overlays; the guide ships through npm, Docker, and the desktop bundle.

## Changed

- **Installation docs:** shorten client setup and group Docker and source-build instructions under running the server.
- **Packaging:** validate published skills and root plugin manifests, remove dependency build-only files and node-gyp intermediates from desktop bundles, and preserve SDK skill runtime modules.

## Fixed

- **House divisions and member ballots** ([#26](https://github.com/cyanheads/canada-parliament-mcp-server/issues/26)): accept the current session picker and use the official `s` query parameter while retaining legacy picker compatibility and strict session validation.
- **HTTP request lifetime:** inherit the framework fix that releases each request's abort signal when its response ends, avoiding retained requests under sustained traffic.

- `@biomejs/biome` 2.6.2 → 2.6.3.
