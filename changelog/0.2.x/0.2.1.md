# 0.2.1 — 2026-10-31

## Added

- **`canparl_search_members` `parliament`** ([#31](https://github.com/cyanheads/canada-parliament-mcp-server/issues/31)): searches a past Parliament's official roster (36th onward) with the current-roster filters; rows carry `from`, `to`, and `current`. An unoffered Parliament fails `invalid_member_filter`; `includeFormer` rejects it with `unsupported_historical_filter`.
- **`canparl_get_member` former MPs** ([#31](https://github.com/cyanheads/canada-parliament-mcp-server/issues/31)): accepts a former member's `personId`, as returned on `canparl_get_vote` ballots, and returns the profile with `current: false`; slug inputs stay current-roster only. New retryable `roster_unavailable` reason when the all-Parliaments roster comes back empty.
- **`canparl_search_speeches` `language`** ([#24](https://github.com/cyanheads/canada-parliament-mcp-server/issues/24)): `en` (default) or `fr` selects the language of `content`, `speaker`, `h1`, `h2`, and the `contains` scan. A field with no text in that language is `null`, never filled from the other; `party` and `riding` stay English in both languages.
- **Input formats in tool schemas** ([#23](https://github.com/cyanheads/canada-parliament-mcp-server/issues/23)): date, session, `personId`, bill-code, and `canparl_get_bill` `section` inputs advertise a `pattern` matching what the handler accepts, and the `canparl_search_speeches` bill scopes require `session` and `code`.

## Changed

- **Shape failures** ([#23](https://github.com/cyanheads/canada-parliament-mcp-server/issues/23)): malformed dates, sessions, `personId`s, bill codes, and sections fail as `-32602 invalid_arguments` instead of a tool reason. `canparl_get_bill` `invalid_bill_code` and `canparl_get_member` `invalid_vote_filter` are removed from the error contracts.
- **`canparl_search_bills` default `limit`** ([#33](https://github.com/cyanheads/canada-parliament-mcp-server/issues/33)): 25 → 10, so a default page fits the response budget.

## Fixed

- **Reading and royal assent times** ([#28](https://github.com/cyanheads/canada-parliament-mcp-server/issues/28)): `milestones` and `royalAssentDate` on `canparl_get_bill` and `canparl_search_bills` read LEGISinfo's clocks as Ottawa time and return the UTC instant (`2026-03-26T14:50:00Z`, not `10:50:00Z`).
- **Text filters** ([#30](https://github.com/cyanheads/canada-parliament-mcp-server/issues/30)): `titleContains`, `subjectContains`, `name`, `riding`, and speech `contains` match regardless of accents, dash and quote styles, and repeated whitespace; returned text and `appliedFilters` are unchanged.
- **Table cells in converted text** ([#25](https://github.com/cyanheads/canada-parliament-mcp-server/issues/25)): a table row's cells join as `a | b` instead of running together, in speech `content` and bill `summary` and `notes`.
- **`canparl_list_reference` `parties`** ([#32](https://github.com/cyanheads/canada-parliament-mcp-server/issues/32)): a session other than the current one fails `incompatible_reference_session`; 0.2.0 answered it with the current roster's parties labelled with that session.

## Security

- The text filters (`titleContains`, `subjectContains`, `name`, `riding`, speech `contains`) and the vocabulary filters process the caller's value in time linear in its length.
